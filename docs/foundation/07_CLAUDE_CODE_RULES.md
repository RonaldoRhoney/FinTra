# Claude Code — Regras Obrigatórias

1. Ler toda a Foundation antes de codificar.
2. Não inventar requisitos, endpoints, provedores ou credenciais.
3. Seguir padrões RhoneyInc.
4. Mobile-first e responsivo em qualquer tela.
5. ZERO-COST-FIRST.
6. Nenhuma API/token pago como dependência crítica sem aprovação.
7. Nunca armazenar senha bancária.
8. Nunca pedir credencial bancária ao usuário.
9. Nunca simular integração Open Finance como se fosse produção.
10. Implementar segurança e isolamento desde V0.1.
11. Criar testes para regras financeiras.
12. IA não pode ser requisito para cálculos essenciais.
13. Dados financeiros devem ser minimizados antes de chegar a agentes/LLMs.
14. Toda integração externa deve ser documentada.
15. Antes de produção, executar auditoria de segurança, privacidade, custo, responsividade e requisitos regulatórios.
16. Se houver dúvida regulatória, parar a implementação da integração e registrar BLOCKER.
