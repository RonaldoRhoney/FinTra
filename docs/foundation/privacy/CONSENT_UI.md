# Consent UI

A jornada deve informar claramente:
- instituição
- dados
- finalidade
- prazo
- status
- possibilidade de revogação

Não usar texto genérico como “aceito tudo”.

O usuário deve possuir Privacy Center com:
- minhas conexões
- consentimentos
- dados compartilhados
- finalidades
- histórico
- revogação
- solicitações de acesso/correção/exclusão quando aplicável
- preferências de comunicação
