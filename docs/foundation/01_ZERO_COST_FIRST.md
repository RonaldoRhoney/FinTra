# ZERO-COST-FIRST

Regra transversal RhoneyInc.

Prioridade:
1. processamento próprio/local
2. open source
3. APIs públicas/oficiais gratuitas
4. infraestrutura autogerenciada
5. serviços externos gratuitos
6. serviços pagos somente mediante decisão explícita

Nenhuma funcionalidade essencial pode depender de:
- tokens pagos
- LLM pago
- API paga
- créditos comerciais
- plano obrigatório
- fornecedor único

O núcleo financeiro deve funcionar sem IA generativa.

Importante: Open Finance não deve ser tratado como uma API pública gratuita comum. A participação, infraestrutura de acesso e responsabilidades precisam ser avaliadas conforme as regras do Banco Central e o modelo jurídico/operacional escolhido.
