# Threat Model

Ameaças mínimas:
- acesso indevido à conta
- vazamento de transações
- exposição de tokens
- abuso de APIs
- privilege escalation
- IDOR
- prompt injection contra agentes
- exfiltração via IA
- webhook falsificado
- replay de eventos
- falha de revogação
- vazamento por logs

Cada ameaça deve ter mitigação e teste.
