# Dashboard

Hierarquia:
1. Saúde financeira
2. Entradas/saídas/saldo
3. Insights prioritários
4. Gastos por categoria
5. Fluxo de caixa
6. Metas
7. Próximas ações
8. Relatórios

Métricas:
- patrimônio consolidado
- saldo
- entradas
- saídas
- taxa de economia
- capacidade estimada de economia
- maiores categorias
- variação
- gastos fora do padrão
- progresso das metas
- projeção

Responsivo: mobile, tablet, desktop e telas grandes. Nenhuma informação crítica depende de hover.
