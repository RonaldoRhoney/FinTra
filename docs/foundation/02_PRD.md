# PRD

## Problema
Usuários possuem contas em várias instituições e têm dificuldade para entender sua vida financeira consolidada, identificar desperdícios, economizar e planejar objetivos.

## Proposta
Consolidar dados autorizados e gerar:
- visão financeira
- categorização
- análise de comportamento
- capacidade de economia
- metas
- projeções
- relatórios
- alertas
- agentes financeiros

## Funcionalidades
### Dados
- contas
- cartões
- saldos
- transações
- receitas
- despesas
- CSV/Excel
- futura integração Open Finance

### Inteligência
- categorias
- recorrência
- média histórica
- variação
- anomalias
- fluxo de caixa
- capacidade de economia
- projeções

### Metas
- viagem
- carro
- moto
- casa/reforma
- reserva
- educação
- investimentos/objetivos financeiros
- meta personalizada

### Agentes
- Financial Analyst
- Savings Coach
- Behavior Agent
- Goal Agent
- Planning Agent
- Investment Education Agent

### Alertas
Somente alertas relevantes, contextualizados e acionáveis.

## Regra de qualidade de insight
Um insight deve considerar relevância, impacto financeiro, confiança, urgência e contexto. Eventos triviais não devem gerar notificações.
